Sniplet Help

How To Use Sniplet

Use this guide when setting up Sniplet for the first time, learning the markup tools, or checking how updates work. This file opens from the Sniplet dropdown so it can travel with the app.

First-Time Setup

Permissions

  1. Install Sniplet into Applications.
  2. Open Sniplet from the menu bar.
  3. Click Request Screen Recording Access.
  4. When macOS asks, approve Sniplet for Screen Recording.
  5. If System Settings opens, turn on Sniplet in the Screen Recording list.
  6. Return to Sniplet and try a capture again.

Capture

Shortcuts

Control-Shift-4Capture a selected area.
Control-Shift-3Capture the current screen.
Control-Option-4Capture a selected area and open markup.
Control-Option-3Capture the current screen and open markup.

Markup

Editing Existing Markups

  • Switch to Move.
  • Click a markup once to select it.
  • Drag the selected markup to reposition it.
  • Use the visible resize handles on box-style markups like blur and redact.
  • Use Delete Selected to remove the selected markup before saving.

Tools

What The Tools Do

PenFreehand markups.
HighlightTranslucent emphasis over text or content.
Arrow, Box, CircleCallouts and shape annotations.
BlurHide sensitive details with a blur region.
RedactHide content with a solid black box.
TextClick to place text directly on the image.

Crop

Crop The Right Way

  • Click Start Crop.
  • Drag the exact area you want to keep.
  • Use a crop preset if you want to lock the crop box to a specific ratio.
  • Click Apply Crop to keep only that area.
  • Click Cancel Crop to back out.
  • Click Revert Original to go back to the original capture.

Saving

Sharing And File Size

  • Save and Close saves the edited image and refreshes the clipboard.
  • Saved captures use compressed JPG output to keep file sizes practical for messaging and sharing.
  • If you cannot paste into a target app, try recapturing at a smaller area or avoiding unnecessary markup layers.

Updates

How To Update

  • Click Update Sniplet from the menu.
  • Sniplet looks for a newer local build and replaces the installed app.
  • Use About Sniplet to check the current version after an update.

If Sniplet changes, this help file should be updated with the new behavior so the in-app instructions stay accurate.
