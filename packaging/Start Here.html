Because Sniplet is shared without Apple notarization, macOS may block anything executable that comes directly from the download. This page gives you the closest reliable one-click path without the Apple fee.

  1. Click Copy Command and Open Terminal.
  2. In Terminal, press Command-V and then Return.
  3. Enter your macOS password once when prompted.
sudo /bin/zsh -c 'set -e; app=""; for volume in /Volumes/Sniplet*; do [[ -d "$volume/.Sniplet.app" ]] && { app="$volume/.Sniplet.app"; break; }; done; target="/Applications/Sniplet.app"; [[ -n "$app" ]] || { echo "Sniplet disk image not found. Keep the disk image open and try again."; exit 1; }; pkill -f "$target/Contents/MacOS/Sniplet" 2>/dev/null || true; rm -rf "$target"; /usr/bin/ditto --noextattr --norsrc "$app" "$target"; xattr -dr com.apple.quarantine "$target" 2>/dev/null || true; xattr -cr "$target" 2>/dev/null || true; spctl --add --label Sniplet "$target" 2>/dev/null || true; spctl --enable --label Sniplet 2>/dev/null || true; open "$target"'

Keep this disk image open while you run the command so Sniplet can be copied into /Applications.
