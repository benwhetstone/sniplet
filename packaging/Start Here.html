Install Sniplet

Because Sniplet is shared without Apple notarization, macOS may block anything executable that comes directly from the download. This page is the safe path around that.

  1. Open Terminal on your Mac.
  2. Copy the command below.
  3. Paste it into Terminal and press Return.
  4. Enter your macOS password once when prompted.
sudo /bin/zsh -c 'set -e; volume=$(find /Volumes -maxdepth 1 -type d -name "Sniplet*" | head -n 1); app="$volume/Sniplet.app"; target="/Applications/Sniplet.app"; [[ -d "$app" ]] || { echo "Sniplet disk image not found."; exit 1; }; pkill -f "$target/Contents/MacOS/Sniplet" 2>/dev/null || true; rm -rf "$target"; /usr/bin/ditto --noextattr --norsrc "$app" "$target"; xattr -dr com.apple.quarantine "$target" 2>/dev/null || true; xattr -cr "$target" 2>/dev/null || true; spctl --add --label Sniplet "$target" 2>/dev/null || true; spctl --enable --label Sniplet 2>/dev/null || true; open "$target"'

Keep this disk image open while you run the command so Sniplet can be copied into /Applications.
